# Lançamento de Moeda: Probabilidade Frequentista

App interativo que mostra a Lei dos Grandes Números: quanto mais lançamentos, mais a proporção de caras se aproxima de 0,5.

Projeto da Semana de Ciência, Tecnologia e Inovação, UEPB, Campus I (2026.2).

**Equipe:** Apollo Borges, Felipe Ferreira e Leonardo Alexandre

## Como rodar

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

O app abre em `http://localhost:8501`.

## Tecnologias

Python, Streamlit, NumPy e Plotly.
